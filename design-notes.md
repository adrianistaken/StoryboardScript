# Workspace design

The storyboard itself is the main visual: a row of paper sections whose natural lengths reveal pacing. Keep the interface quieter than the writing.

Palette: canvas `#f4f2eb`, paper `#fffefb`, ink `#292e32`, secondary ink `#687078`, rule `#dcded7`, and a muted marine accent `#3b6576`. No decorative textures or gradients.

Typography: locally bundled Source Sans 3 for controls and narration; Georgia for the product title and large introductory text. Numerals identify actual section order. Left-aligned text throughout.

Home: compact identity bar, a spacious introduction beside an understated script-column illustration, then saved projects as practical rows. The import action remains primary. No marketing navigation or invented social proof.

Workspace: project toolbar, a thin totals/navigation strip, then top-aligned columns. Following the user's local review, word count and estimated time replace the section number above the title. Empty image trays collapse to a small Add image button; only attached images use the thumbnail tray. Remove reserved heading space so more script is visible. A persistent bottom navigation rail makes horizontal movement usable even in long scripts.

Review: compare proposed section headings and their text before creating the project. Excluded preamble is inspectable.

Brief review: warm paper is explicitly requested, but terracotta, decorative numbering, and a generic dashboard grid are unnecessary. Use blue sparingly for actions and selected states; make the columns and readable writing the distinctive feature. Verify four-column viewing, natural height differences, focus visibility, and no clipped controls at desktop widths.
